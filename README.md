# CPI Technologies Lead Funnel

Zweiter Funnel für CPI Technologies ohne Buch-Fokus. Ziel ist Lead-Qualifizierung für AI-, Software-, SaaS-, MCP- und Blockchain-Projekte.

## Dateien

- `index.html` - Funnel-Struktur und Screens
- `styles.css` - Tech-Design, Animationen und Responsive Layout
- `script.js` - Quiz-Logik, Website-Validierung und lokale Lead-Speicherung
- `assets/cpi-logo.svg` - CPI Logo

## Live-Schaltung

Der Funnel ist statisch und kann direkt auf Vercel, Netlify oder GitHub Pages deployed werden.

Für echte Leads muss das Formular an ein CRM, einen Webhook oder eine E-Mail-Automation angebunden werden. Aktuell speichert der Prototyp die Anfrage lokal im Browser unter `cpi-lead-funnel-submission`.
